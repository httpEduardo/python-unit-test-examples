# Python Unit Test Examples

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)

A small collection of introductory `unittest` examples covering simple arithmetic cases and the structure of a test class.

## Run an example

Run any example file with Python, for example:

```bash
python test1.py
```

The examples use Python's standard library and require no third-party packages.
